## 배운 점
- **MCP = 표준 플러그** — 한 번 연결하면 어디서나 같은 방식으로 도구를 쓴다
- **어디에 연결하느냐**(채팅 · 데스크톱 · Claude Code)에 따라 할 수 있는 일이 달라진다
- 권한은 좁게: 읽기부터 시작하고, 쓰기는 먼저 보여 주고 확인받는다. 삭제 · 닫기 · 머지는 사람이 한다
- 도구도 코드처럼 레포로 공유한다: `.mcp.json` + `CLAUDE.md`. 키는 `${환경변수}` 이름만 적는다

> 이 레포에는 실제 토큰이나 `.env`가 들어 있지 않습니다. 데이터는 모두 가짜예요.
