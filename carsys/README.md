# carsys · 자동차 예약 시스템 더미 데이터

> 모든 데이터는 가짜예요. 전화번호는 `010-0000-xxxx`, 이메일은 `@example.com`만 써요.

| 파일 | 내용 |
|---|---|
| `data/reservations.csv` | **예약 200건** (기준일 2026-11-17 · 과거 120일 ~ 미래 60일) |
| `data/cars.csv` | 차량 40대 (현대 · 기아 · 제네시스 · 테슬라 · KG모빌리티) |
| `data/customers.csv` | 고객 80명 (등급: 일반 · 실버 · 골드 · VIP) |
| `data/branches.csv` | 지점 6곳 (서울역 · 강남 · 김포공항 · 부산역 · 제주공항 · 대전역) |
| `schema.sql` | 테이블 4개 (PostgreSQL · Supabase) |
| `seed.sql` | 테이블 생성 + 데이터 INSERT 한 번에 |
| `generate.py` | 데이터 생성기 (`python generate.py` · SEED 25로 항상 같은 결과) |

## 데이터 규칙
- 예약 상태는 날짜에 맞춰요. 지난 예약은 반납완료 · 취소 · 노쇼, 오늘 걸친 예약은 이용중, 앞으로의 예약은 예약확정 · 결제대기 · 취소
- 같은 차가 같은 기간에 두 번 예약되지 않아요
- 요금 = 1일 요금 × 일수 − 등급 할인(실버 5% · 골드 10% · VIP 15%) + (보험 + 옵션) × 일수
- CSV는 UTF-8(BOM)이라 엑셀에서 바로 열어도 한글이 깨지지 않아요

## Supabase에 넣기
SQL Editor에 `seed.sql`을 붙여 넣고 실행하면 돼요.
