# 클래스로 P2 기획서 (가짜 데이터)

## 한 줄 소개
동네 원데이 클래스를 찾고 바로 예약하는 서비스.

## 타깃
- 주 타깃: 퇴근 후 취미를 찾는 20~30대 직장인
- 보조 타깃: 주말 체험을 찾는 대학생

## 문제
- 클래스 정보가 SNS 에 흩어져 있어 비교가 어렵다.
- 예약이 DM · 전화로만 돼서 번거롭다.

## MVP 기능
1. 회원가입 (이메일 · 닉네임)
2. 클래스 목록 (카테고리 · 지역 · 가격 필터)
3. 예약 (날짜 · 인원 선택, 예약 확인 화면)

## 화면
- 메인 화면: 추천 클래스 · 카테고리 바로가기
- 목록 화면: 필터 · 정렬
- 상세 화면: 소개 · 일정 · 예약 버튼

## 사람과 AI 의 역할
- AI(team MCP): 할 일 · 진행률 · 문서 찾기 — 읽기 전용
- 사람: 이슈 닫기 · 머지 · tasks.csv 변경(PR) · 최종 판단
