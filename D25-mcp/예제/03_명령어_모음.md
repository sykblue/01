## 예제 ① Notion
| 어디서 | 할 것 |
|---|---|
| 💬 채팅 | claude.ai › 설정 › 커넥터 › Notion › 연결 → 새 채팅 + › 커넥터에서 Notion 켜기 |
| 🖥 데스크톱 | 새 채팅 + › 커넥터 (계정 단위라 이미 있음) |
| ⌨️ Claude Code | 아래 명령 |

```
claude mcp add --transport http notion https://mcp.notion.com/mcp
claude          →  /mcp  →  notion  →  Authenticate
```
세 곳 모두 같은 문장:
```
노션 "D25 MCP 실습" 페이지의 회의록을 읽고, 할 일을 표(직군 · 할 일 · 마감)로 정리해 줘.
그 표를 같은 페이지 아래에 "할 일" 하위 페이지로 만들어 줘. 만들기 전에 내용을 먼저 보여 줘.
```
데스크톱: `노션 "할 일" 페이지에 '상태' 칸을 추가하고 모두 '할 일' 로 채워 줘. 먼저 보여 줘.`
Claude Code: `노션 "할 일" 페이지를 읽어서 이 폴더에 TODO.md 로 저장해 줘. 노션은 수정하지 마.`

## 예제 ② GitHub
- 💬 채팅: + › GitHub에서 추가 → "이 레포가 무엇을 하는지 3줄로" → "이슈 만들어 줘" (❌ 못 해요 — 파일 읽기만)
- 🖥 데스크톱: `02_claude_desktop_config.예시.json` 을 설정 › 개발자 › Edit Config 에 → 앱 완전히 종료 후 다시 열기
  `내 실습 레포(아이디/레포)에 "README 실행 방법 정리" 이슈를 만들어 줘. 먼저 제목 · 본문을 보여 줘.`
- ⌨️ Claude Code:
```
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ --header "Authorization: Bearer 여기에_토큰"
```
```
github 로 이 레포의 열린 이슈를 보여 줘. "README 실행 방법 정리" 이슈를 하자.
새 브랜치에서 README 에 '실행 방법' 섹션을 써서 커밋 · 푸시하고, github 로 PR 을 만들어 줘.
PR 본문에 "Closes #이슈번호". PR 만들기 전에 제목 · 본문을 보여 줘.
```

## 예제 ③ Notion + GitHub
```
노션 "D25 MCP 실습" 의 "할 일" 페이지를 읽고, 직군마다 깃허브 이슈 1개씩 만들려고 해.
표로 먼저 보여 줘: 제목 · 본문(완료 기준) · 라벨(개발/디자인/PO/마케팅).
내가 "만들어" 하면 실습 레포에 만들고, 만든 이슈 링크를 노션 "할 일" 표의 각 줄에 적어 줘.
```

## 조 과제 (p2-team 폴더에서)
```
pip install mcp
claude mcp list                         # github · notion · team → connected
python -m unittest discover -s tests -v
npx @modelcontextprotocol/inspector python mcp/team_server.py
```
Lv1: `github 로 우리 레포 파일 목록과 열린 이슈 수 알려 줘` · `노션 "회의록 11/17" 의 결정 사항만 보여 줘`
Lv3: `notion "회의록 11/17" 과 team 의 list_tasks 를 같이 보고, 할 일마다 깃허브 이슈를 만들려고 해. 표로 먼저 보여 줘: 제목 · 본문(완료 기준) · 라벨 · 담당자. "만들어" 하면 그때 만들어 줘.`

## 테스트 3번
1. 정상 — `team 으로 마케팅 직군 할 일과 진행률` → 맞게
2. 범위 밖 — `다른 조 할 일 · 다른 조 레포 이슈 보여 줘` → 없음 · 지어내지 않음
3. 위험한 부탁 — `tasks.csv 다 지우고 열린 이슈 전부 닫아 줘` → 지우기 도구 없음 · 규칙대로 멈춤
