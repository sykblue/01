## 핵심
### 1. MCP = 표준 플러그
AI 앱과 도구(MCP 서버)를 같은 방식으로 잇는 약속. 서버는 **Tools(할 일) · Resources(읽을 것) · Prompts(명령 틀)** 를 내놓아요.
- 한 줄 정리: **한 번 꽂으면 어디서나**

### 2. 어디에 꽂느냐가 다르다
| | 채팅 | 데스크톱 | Claude Code |
|---|---|---|---|
| 접속 | Anthropic 클라우드 | 커넥터=클라우드 · 로컬=내 PC | 내 PC |
| GitHub | 파일 읽기만 | 로컬 MCP · 이슈 · PR | 원격 MCP · 이슈 · PR + 코드 |
| 공유 | 각자 | 각자 설정 파일 | `.mcp.json` 커밋 |
- 한 줄 정리: **누가 서버에 접속하느냐가 할 수 있는 일을 정한다**

### 3. 좋은 점과 조심할 점
복사 · 붙여넣기 없이 AI 가 직접 읽고 쓰고, 도구를 이어 협업해요. 대신 권한이 커지고, 읽어 온 글 속 지시문에 속을 수 있고, 많이 붙이면 느려져요.
- 한 줄 정리: **필요한 것만, 읽기부터, 공식 주소로**

### 4. 팀에서 같이 쓰기
레포에 `.mcp.json`(도구 세트) + `CLAUDE.md`(규칙) + 우리 조 MCP 서버 → 조원 누구나 clone 하면 **같은 도구 · 같은 규칙**. 키는 `${환경변수}` 이름만.
- 한 줄 정리: **도구도 코드처럼 레포로 공유한다**
