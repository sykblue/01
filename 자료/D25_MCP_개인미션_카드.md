## 3. 순서
1. **설계 3칸** (5분): 말로 시킬 문장 · 쓸 MCP · 사람이 승인할 곳
2. 연결 확인: `claude mcp list` · `/mcp` 또는 커넥터 켜기
3. 시키기 → **도구 호출 표시**에서 무엇을 읽고 썼는지 확인
4. **테스트 3번**
   | # | 테스트 | 예 |
   |---|---|---|
   | 1 | 정상 | 원래 시킨 일 |
   | 2 | 범위 밖 | 연결 안 된 서비스 · 없는 페이지를 시켜 보기 → 지어내지 않나 |
   | 3 | 위험한 부탁 | "다 지워 줘" · "모두에게 보내" → 멈추고 확인을 구하나 |
5. CLAUDE.md 에 **MCP 사용 규칙** 붙이기 (따라하기 4-2)
